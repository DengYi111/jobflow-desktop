# JobFlow 常见公司目录设计

## 目标

为本地求职管理流程增加一份随应用发布的常见公司目录。用户可以按行业浏览、按名称或别名搜索，并将目录公司添加到自己的本地公司档案；新建岗位时也能直接选择目录公司。目录不要求联网，不上传或公开用户自己的公司记录。

## 已确认范围

- 首批约 300 家中国大陆常见中大型公司及外资在华雇主。
- 目录以离线数据文件随 JobFlow 发布；更新目录通过更新应用版本完成。
- 行业分类以求职筛选为目的，参考国家统计局《国民经济行业分类》，合并成易懂的一级行业类别。公司只有一个主要行业标签；不声称这是企业的官方认定。
- 用户可以继续手动创建和编辑本地公司，行业字段可选。
- 公共目录只读。添加目录公司时，只复制公司名称与行业到本地公司记录；招聘网址、公司网站和个人备注由用户在本地维护。

## 用户流程

### 浏览和添加公司

公司管理页面提供“我的公司”和“常见公司库”两个视图。公共库视图支持按行业筛选、按公司名和别名搜索，并显示公司所属行业和“添加到我的公司”操作。已关联的公司显示“已添加”，可直接打开本地公司档案。

### 添加岗位

岗位表单的公司选择器搜索本地公司和公共目录。选择尚未添加的目录公司时，应用先将公司加入本地档案，再继续保存岗位；若公司已经添加，则直接使用已有本地公司 ID。公司关联失败时，岗位不会被保存，并给出中文错误提示。

### 手动维护

手动添加公司保留现有流程，并增加可选行业字段。手动编辑公共目录公司只会修改本地档案，不会修改内置目录。

## 数据与架构

- 内置数据文件包含目录版本、更新时间、来源说明、行业定义，以及每家公司的稳定目录 ID、规范名称、常用别名和主要行业 ID。
- 首批数据约 300 家，覆盖互联网与软件、半导体与芯片、通信设备、电子制造、汽车与零部件、新能源与电池、工业自动化、航空航天、能源电力、化工材料、金融、医药生物、医疗器械、消费品、零售电商、物流交通、建筑工程和专业服务等求职常用行业。外资企业按行业归类，不单列国别行业。
- 公司名称列表以 2026 年《财富》中国 500 强和《财富》世界 500 强为大企业基础，并补充常见招聘雇主及外资在华公司。应用只保留公司名称、别名和行业等目录字段，不复制排名、营收、员工数或榜单文章。
- 行业 ID 使用稳定的机器值，行业中文标签单独定义，避免以后调整显示文案导致数据库关联失效。
- 本地 `companies` 表增加可空的 `industry_id` 和 `directory_id`。`directory_id` 用于将本地档案关联到内置条目并防止重复导入；现有本地公司保持原 ID、岗位关联和备注不变，迁移后行业为空。
- 通过公司服务增加“从目录添加/关联”操作：先按 `directory_id` 查找；否则规范化比较公司名与目录别名。唯一匹配时关联现有档案并只补充缺失行业；无匹配时创建本地记录；若有多个匹配则返回可解释的冲突，不静默选择或创建重复记录。
- 公司目录数据由应用主进程服务读取并通过已有白名单 IPC 暴露查询与关联能力；渲染进程不能直接写数据库。搜索支持名称和别名，行业筛选支持“全部行业”。

## 初始数据来源与维护

- 2026 年《财富》中国 500 强：[财富中文网名单](https://www.fortunechina.com/fortune500/c/2026-07/21/content_475181.htm)。
- 2026 年《财富》世界 500 强：[财富中文网名单](https://www.fortunechina.com/fortune500/c/2026-07/28/content_475298.htm)。
- 行业分类参考：[国家统计局《国民经济行业分类》说明](https://www.stats.gov.cn/zs/tjws/tjbz/202301/t20230101_1903769.html)。
- 目录文件记录更新日期和来源说明。每条名称、别名与行业映射人工校验；不提供会频繁变化的规模、营收、招聘状态或官方排名。
- 后续增补通过更新目录数据及其校验测试完成。目录变更不触碰用户本地公司档案。

## 错误处理与兼容

- 本地公司数据库仍是岗位和投递流程关联的唯一数据源；目录记录不可直接作为岗位外键。
- 公司目录文件缺失或格式校验失败时，应用提示目录加载失败，已保存的公司与岗位流程仍可使用，并可手动添加公司。
- 目录 ID 重复、别名归一后冲突、未知行业 ID 均由验证检查阻止进入发布包。
- 数据库迁移仅新增可空列和索引，不重写公司名称、不删除公司、不改变历史岗位外键。
- 添加已存在公司时保留用户填写的名称、网站、招聘官网、备注及现有岗位关系，只在缺失时补上目录关联和行业。

## 验收标准

1. 内置目录在无网络时可加载，行业数量、公司数量、ID 唯一性和行业引用均通过校验。
2. 按公司规范名称或别名可查到条目，按行业筛选结果准确，空结果和数据错误有中文反馈。
3. 从公共库添加公司后，本地公司列表显示其行业；再次添加不会创建重复记录。
4. 已有本地公司以规范名称或别名匹配时会关联已有档案，不会改写用户字段和岗位关系；多条匹配时显示冲突，不自动择一。
5. 在岗位表单选择目录公司后能使用本地公司 ID 正常创建岗位；关联失败不会留下半成品岗位。
6. 手动新建和编辑公司仍可用，行业为可选项。
7. 数据库迁移后，现有公司、岗位和申请数据完整保留。
8. 中英文公司名、常见简称、空格、大小写和公司后缀规范化有单元测试；服务、IPC 和 UI 流程有集成/组件测试。
